# applied-ai-homework
Homework Repository for Applied AI Homework

# Repository Information
* UV is used for this repository
* .venv is located applied-ai-homework/
* .venv is shared among all homework directories
* Using python v3.12

# How to Install Packages 
* While in the directory of the desired homework, run ```pip install -r requirements.txt``` or ```uv pip install -r requirements.txt``` if you're using uv
